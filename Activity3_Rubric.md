# Activity 3: Interactive Dynamic List Rubric

*   **State Management (useState) (Max: 25 pts):** Assign up to 25 pts for tracking both input text and array data using useState. Deduct if state updates directly or fails to clear input on submit.
*   **List Rendering (FlatList) (Max: 25 pts):** Assign up to 25 pts for implementing <FlatList> with data, renderItem, and keyExtractor. Deduct if map() or hardcoded items are used.
*   **User Interactivity & Input Handling (Max: 25 pts):** Assign up to 25 pts for <TextInput> handling and touchable components (TouchableOpacity/Pressable) triggering add and delete actions. Deduct if interaction buttons are missing.
*   **UI Layout & Submission Integrity (Max: 25 pts):** Assign up to 25 pts for clean row item layout and complete submitted files. Deduct for missing dependency files.
