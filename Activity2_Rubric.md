# Activity 2: Static Single-Page UI Rubric

*   **Component Usage & JSX Structure (Max: 25 pts):** Assign up to 25 pts for correct core components (View, Text, Image, ScrollView) and proper nesting. Deduct for missing components or syntax errors.
*   **Flexbox Layout & Responsiveness (Max: 30 pts):** Assign up to 30 pts for proper StyleSheet.create, flexDirection, justifyContent, and flex properties. Deduct for fixed height/width px usage or broken layouts.
*   **UI Aesthetics & Visual Polish (Max: 25 pts):** Assign up to 25 pts for consistent padding, margins, colors, and visual hierarchy. Deduct for unstyled default views.
*   **Code Organization & Completeness (Max: 20 pts):** Assign up to 20 pts for clean, well-structured modular code. Deduct for unorganized styles or missing custom component files.
