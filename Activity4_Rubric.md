# Activity 4: Multi-Screen Navigation Rubric

*   **Navigation Architecture (Max: 25 pts):** Assign up to 25 pts for correct <NavigationContainer> and createNativeStackNavigator configuration. Deduct for missing navigation wrapping.
*   **Screen Implementation & Flow (Max: 25 pts):** Assign up to 25 pts for implementing at least 3 distinct, fully populated screens with logical flow. Deduct if fewer than 3 screens exist.
*   **Data Transfer (route.params) (Max: 25 pts):** Assign up to 25 pts for passing data via navigation.navigate() and receiving via route.params. Deduct if parameters fail to render dynamically.
*   **Reverse Navigation Mechanics (Max: 15 pts):** Assign up to 15 pts for custom buttons utilizing navigation.goBack(). Deduct if goBack logic is missing or broken.
*   **Code Completeness & Files (Max: 10 pts):** Assign up to 10 pts for submitting all required screen components and mock data files. Deduct for import resolution errors.
